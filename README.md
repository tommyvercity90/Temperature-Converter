🌡️ Temperature Converter

A simple and responsive Temperature Converter built using HTML5, CSS3, and JavaScript.

This project converts temperatures between Celsius, Fahrenheit, and Kelvin in real time. It was created to practice form inputs, JavaScript functions, calculations, validation, and DOM manipulation.

🚀 Features

Convert between Celsius, Fahrenheit, and Kelvin.

Live conversion while typing.

Separate input fields for each temperature unit.

Validation for invalid temperature values.

Prevents temperatures below absolute zero.

Displays error messages for invalid input.

Clear button to reset all fields.

Responsive design for desktop and mobile devices.

Clean and simple user interface.

🛠️ Technologies Used

HTML5 – Creates the structure of the application.

CSS3 – Provides styling, layout, responsiveness, and visual design.

JavaScript – Handles calculations, validation, events, and DOM updates.

🧮 Conversion Formulas
Celsius to Fahrenheit
°F = (°C × 9/5) + 32

Celsius to Kelvin
K = °C + 273.15

Fahrenheit to Celsius
°C = (°F − 32) × 5/9

Fahrenheit to Kelvin
K = (°F − 32) × 5/9 + 273.15

Kelvin to Celsius
°C = K − 273.15

Kelvin to Fahrenheit
°F = (K − 273.15) × 9/5 + 32

✅ Validation

The application checks for:

Empty input.

Invalid numerical values.

Temperatures below absolute zero.

Kelvin values below 0 K.

For example:

Kelvin cannot be below 0 K.

💻 How to Run

Download or clone this repository.

Open the project folder:

temperature-converter/


Open index.html in any modern web browser.

No additional installation or dependencies are required.

📸 How It Works

Enter a temperature in any one of the three fields:

Celsius      → 25
Fahrenheit   → 77
Kelvin       → 298.15


The other fields are automatically updated with the converted values.
